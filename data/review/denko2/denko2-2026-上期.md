## 計算問題（calcTemplate）にした／しなかった判断

**calc にした（2問）**

- **問3（発熱量）**：図がなく、消費電力と時間だけの計算。`P`（300〜1000 W）と `t`（1〜3 h）をプール化。
  誤答は「kJ に直し忘れ（W·h のまま）」「2倍」「半分」を式で表現。
- **問8（許容電流と電流減少係数）**：図がない。断面積 `A` を 2 / 3.5 / 5.5 / 8 mm² でプール化し、
  formula 内で許容電流表（27 / 37 / 49 / 61 A）を三項演算子で引いて 0.63 を掛けている。
  誤答は「電流減少係数の掛け忘れ（＝表の値そのもの）」「2倍」「半分」。
  電線本数は 4 本（係数0.63）に固定した。本数まで変えると係数との整合が取れなくなるため。

**calc にしなかった計算問題とその理由**

- 問1（合成抵抗）、問6（電圧降下）、問7（単相3線式）、問9（幹線）：いずれも**図の中に数値が描き込まれている**。
  問題文で「各抵抗は {R} Ω」と言い換えることは形式上できるが、図に「5 Ω」「12 m」「1 600 W」等が残るため
  受験者が混乱する。`DATA_FORMAT.md` の原則どおり static のままにした。
- 問5（三相Y結線）、問4（力率）、問10（分岐回路）、問12（コード）：答えが数値の計算ではない（組合せ・記述選択）。

    電磁開閉器・カバー付ナイフスイッチ・ライティングダクトは特定電気用品以外。ロの解説を「フロートスイッチは特定電気用品だが
    電磁開閉器が特定以外なので組合せとして誤り」に修正済み。
- **問41・問47・問49（ボックス内の接続）**：配線図から各ボックスに集まるケーブル本数と心線を数え直して
  公式解答と一致することを確認した（問47 は「小4個・刻印○3＋小1」、問41 は「中2＋小1」、問49 は「4本用2＋2本用1」）。

## 仕様への提案（変更はしていない）

1. **`samples.json` と実データの id 衝突**
   `public/data/denko2/questions/samples.json` は `denko2-2026-上期-21 / -24 / -25 / -28` という
   実在の examId + 問番号の id を持っており、本回のデータと id が重複して `npm run validate` がエラーになった。
   やむを得ず `subject.json` の `questionFiles` から `samples.json` を外した（`["denko2-2026-上期.json"]` のみ）。
   結果として「questionFiles に載っていない」という WARN が1件出るが、エラーは0件。
   提案：samples.json の id を `denko2-sample-01` のように実在しない形にするか、
   validate 側で `samples.json` を検証対象から明示的に除外する（ファイル名でスキップ）と扱いやすい。

2. **グループの「分野をまたぐ関連付け」**
   問39 のように、知識としては分野5（絶縁抵抗の基準値）だが出題形式としては分野6（配線図）という問がある。
   1グループ＝1分野の制約は維持したまま、`groups.json` に `relatedGroups: ["g5-zetsuen-teikou-kijun"]` のような
   任意フィールドがあると、復習導線を作りやすい。

3. **写真・図の選択肢に「短い説明」を入れるかどうかの指針**
   `DATA_FORMAT.md` は「短い説明の方がよい」としているが、問35（ペンダントの図記号）や問46（点滅器の写真）では
   説明を書くと答えそのものになってしまう。今回は
   **「選択肢そのものが答えの識別対象になっている問は『図イ／写真イ』のラベルのみ」**、
   **「選択肢が条件の組合せを表す図の問（問10・問27・問42・問41・問47・問49）は説明文を入れる」**
   というルールで書き分けた。この方針を DATA_FORMAT.md に明記してもらえると、回ごとのぶれがなくなる。

4. **`extract_pdf.py` の figure bbox**
   問7 のように、自動検出した図の bbox の上端が本文のアンダーラインや空欄枠を拾って大きく上にずれることがある。
   「図の bbox が問い欄の高さの半分以上を占める場合は疑わしい」といった警告を出力に含めると、
   手作業での確認漏れが減らせる。
