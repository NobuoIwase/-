## 自信が持てなかった箇所（次工程で重点的に見てほしい）

1. **問31（①＝確認表示灯）の解説の書き方**
   図記号は「点滅器と並んで壁に描かれた白丸○」で、公式解答が確認表示灯なのは確実。ただし
   「白丸○ ＝ 確認表示灯」と JIS の記号表がそのまま対応しているのか、位置（点滅器と並ぶか、
   照明位置か）で白熱灯と区別しているのかは断定できていない。解説では
   「点滅器と並べて壁に描かれた白丸」という位置の情報で説明している。JIS C 0303 の記号表と
   突き合わせて表現を確認してほしい。
2. **問32（②＝ワイドハンドル形点滅器）の distractor の説明**
   図記号が黒いひし形◆であること、公式解答がワイドハンドル形点滅器であることは確認済み。
   一方で「一般形調光器・ワイド形調光器の図記号がどう描かれるか」は断定できなかったので、
   「調光器は点滅器とは別の図記号で表され、ひし形ではない」という書き方に留めている。
3. **問48（使用しているコンセント）の イ・ロ の識別**
   ニ（接地極付接地端子付＝EET）が正解であることは図面の「EET」「2EET」から確実。
   イ・ロは接地極付だが接地端子がなく、刃受の向き（125 V用＝縦／250 V用＝横）から
   イは250 V用と読めるものの、15 A用か20 A用かまでは写真から確定できなかった。
   解説では「図面の接地極付コンセントはすべて2口（2E）か接地端子付（EET・2EET）で、
   1口の接地極付コンセント単体は使われていない」という、図面側から確実に言える理由にしている。
4. **問46 ロ の写真の種類**
   黒色シースの丸形3心ケーブル（CVと思われる）だが、CVVなど他の可能性も否定しきれないので、
   解説では「黒色シースの丸形3心ケーブル」とだけ書き、
   「この配線図の屋内配線はVVF（平形）」という理由で不適切としている。
5. **問20 ハ（コンクリート壁に直接埋設）**
   VVFをコンクリートに直接埋め込めないことは確実だが、根拠条文を第164条（ケーブル工事）と
   だけ挙げている。条項番号まで詰めるなら要確認。
6. **問43 ロ・ハ・ニ の材料名**

   「金属製の露出形ボックス」「金属製の埋込ボックス」「八角形のアウトレットボックス」と
   写真から見た特徴で書いており、正式な製品名は詰めていない。

## 仕様への提案

- `explanation.whyOthersWrong` は「正答の位置は空文字」という仕様だが、選択肢をシャッフルする都合上、
  配列の index が `choices` の index と対応していることが前提になっている。
  今回のように写真選択肢（`choicesFigure` ありでシャッフルなし）の問と、
  テキスト選択肢（シャッフルあり）の問が混在するので、
  データ検証で「`whyOthersWrong[answer]` が空文字であること」を明示的にチェックすると事故が減ると思う。
- 配線図問題（分野6）は同じ `sharedFigure` を20問が共有する。アプリ側で「図面を一度開いたら
  その回の配線図問題を連続で出す」挙動になっているとのことなので問題ないが、
  データ側にも「この図面の注意書き」（木造か否か、ケーブル工事か否か、漏電遮断器の有無）を
  持たせられると、解説で毎回書かずに済み、出題時にも提示できて親切だと思う。
  例: `sharedFigureNote: "木造1階建住宅／屋内配線はVVFによるケーブル工事／漏電遮断器30 mA・0.1秒"`。

1. **問5 `whyOthersWrong[0]`（2.4 kW）** … 「相電流20 A，抵抗8 Ωから1相3.2 kW」と書いてあり，
   選択肢の2.4 kWをまったく説明していなかった。
   → 「線間電圧を半分の100 Vと誤ると3×10²×8＝2 400 W」に差し替え。
2. **問5 `whyOthersWrong[1]`（4.8 kW）** … 「6 Ωを抵抗とみなし相数も取り違えた」というこじつけ。
   → 「Z＝8＋6＝14 Ωと単純に足すと3×14.3²×8≒4 900 W」という自然な誤り方に差し替え。
3. **問6 `whyOthersWrong[1]`（26 W）** … 「√3×0.15×10≒2.6」と書いており，選択肢26に対して1桁違う。
   → 「3を√3と取り違えて√3×10²×0.15≒26」に訂正（数値が一致する）。
4. **問9 `references`** … 分岐幹線の3 m／8 m・35 %／55 %の規定は**電技解釈第148条（低圧幹線の施設）**であり，
   第149条（低圧分岐回路等の施設）ではない。→ 第148条に訂正。
   （問10の分岐回路の表は第149条で正しいのでそのまま）
5. **問32 `whyOthersWrong[1][2]` と `supplement`** … 「調光器は別の図記号でひし形ではない」とだけ書かれ，

   「②には矢印がないので調光器ではない」と具体的に書き直した。
