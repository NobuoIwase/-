## note を付けた問

- **問28**（電気工事士法の作業範囲）: 2023年3月施行の法改正で対象が「一般用電気工作物等」に改称。用語のみで正誤は変わらないため `note` のみ、`active` のまま。
- **問30**（一般用電気工作物の要件）: 出題当時「太陽電池発電設備は出力50 kW未満が小出力発電設備」だったが、
  2023年3月施行の改正で10 kW以上50 kW未満は「小規模事業用電気工作物」（事業用電気工作物）に移った。
  **選択肢ニ（出力15 kWの太陽電池発電設備を備えた低圧受電の幼稚園）の扱いが現行制度では微妙**で、

  という解釈になり得る（電気事業法第38条第1項は小規模発電設備との接続を許容している）。
  答えが変わると断定できないため `retired` にせず、`note` に「要確認: …」として `active` のまま残した。
  **次工程で法解釈の裏取りをしてほしい。**

## calc 化

- **問7のみ `calc`**（許容電流×電流減少係数）。`n`（管内本数）と `k`（電流減少係数）をパラメータにし、
  `accept` で「4本→0.63 / 5〜6本→0.56 / 7〜8本→0.49」の対応を強制している。採用可能な組合せは5通り、
  答えは 22 / 20 / 17 A の3種類。
- **直径をパラメータにできなかった。** `src/engine/calc.ts` の置換は `String(params[k])` なので
  `2.0` が `"2"` と表示されてしまい、「直径2 mm」という誤った表記になる。そのため直径は2.0 mm固定にした。
  → **仕様への提案:** `calcTemplate` に小数桁指定（例 `paramDigits: { "d": 1 }`）があると、
  直径1.6/2.0/2.6 mmのような値もパラメータ化できる。
- 問1・2・4・5・6・8・10 は図の中に数値が描き込まれているため `static` のまま（§4の除外条件）。
- 3本以下（減少係数0.70）は 35×0.7＝24.5 となり四捨五入の扱いが割れるおそれがあるので、
  `params` の `n` から3を外した。

### 見つけて直した問題（7件）

1. **問19 whyCorrect（法令の誤り）** … 金属可とう電線管のD種接地省略条件に「（乾燥した場所に施設するとき）」と
   金属管（解釈第159条）側の要件が混ざっていた。解釈第160条の省略条件は**管の長さ4 m以下のみ**。文を修正。
2. **問19 supplement（法令の誤り）** … 「300 Vを超える場合は原則C種で、**省略できるのは**接触防護措置を施したときの4 m以下」は誤り。
   300 V超は接触防護措置により **C種→D種に緩和**できるだけで省略はできない。あわせて金属管と金属可とう電線管の
   省略条件を同一視していた点も、条ごとに書き分けて全面的に書き直した。
3. **問41 supplement（数値基準の誤り）** … 大スリーブの例に「5.5 mm²×2〜3本」とあったが、5.5 mm²×2本は断面積11 mm²で**中**。
   選定表では2.6 mmと5.5 mm²が同じ欄で扱われ「2本→中、3本→大」。中・大の例示を訂正し、その一文を追記。
4. **問7 calcTemplate の誤答生成** … `distractors` が `answer*0.5` / `answer*1.5` で、元パラメータでも選択肢が
   **11 / 22 / 33 / 35** となり原問（17 / 22 / 30 / 35）を再現できず、11 Aという実試験にない値が出ていた。
   `27*k`（1.6 mmと取り違え）/ `48*k`（2.6 mmと取り違え）に変更。これで
   n=4 → 17/22/30/35（原問と完全一致）、5〜6本 → 15/20/27/35、7〜8本 → 13/17/24/35 となり、
   supplement の許容電流表（1.6→27 / 2.0→35 / 2.6→48）ともつながる誤答筋になった。
5. **問8 whyOthersWrong[0]（説明の不整合）** … 選択肢イ「2.6」に対し「小数点の位置を誤った値です。I²r＝15 W」とあり、
   2.6 の由来（√3×I²r≒26 の桁誤り）と噛み合っていなかった。「√3を掛けた26 W（ハ）の桁を誤った値」に書き直した。
6. **問18 の図が切れていた** … `--y0 0.36` で写真の上端2割が欠け、黒いストリッパの柄が切れていた。
   `--y0 0.185` で切り直し、`public/.../q18_fig.png` を削除してから `publish_figures.py` を再実行して差し替え。
7. **問41 whyCorrect の紛らわしい表記** … 「三相200 V回路ⓐ」が問37の「二重丸ⓐ（単相200 V回路）」と同じ字面だったので、
   「動力分電盤P-1の□で囲んだⓐ」と明記した。あわせて問30の `note` を、現行制度での読み方が分かる書き方に直した（要確認は維持）。

### 疑ったが誤りではなかった主な点

- **⑲の図記号**（Sを丸で囲み、さらに黒く塗った四角で囲む）＝**電流計付箱開閉器**。400 dpiで
  工場内の細線の□Sと明確に描き分けられていることを確認し、外部情報でも「Sが○で囲まれ、さらに正方形で囲まれている記号」で裏が取れた。
- **問31・42・43の連動**（作成担当が再確認を求めていた箇所）。公式解答との整合だけでなく**図面自体から確定**できた。
  1階階段まわりを拡大すると、**立上り記号（○＋上向き矢印）は階段灯ハの位置にあり**、2階側の同じ位置に引下げ（○＋下向き矢印）がある。
  電源は2階L-2のⓒ回路なので、接地側電線は⑫→⑬→①と降りるほかない。よって

  ⑫に集まるケーブルが4本（L-2・⑬・イ群・ロ群）であること、L-2からの線とロ群の縦線が交差するだけで接続していないことも拡大して確認した。
