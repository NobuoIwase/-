# 問題データ形式仕様

対象は `public/data/<subject>/` 以下の JSON。型の正本は `src/types.ts`、検証は `npm run validate`（`scripts/validate-data.ts`）。

## ディレクトリ

```
public/data/
  subjects.json                        試験種別の一覧
  denko2/
    subject.json                       分野定義・模擬試験設定・読み込む questions ファイル
    groups.json                        類似問題グループの定義
    questions/<examId>.json            1 回分の問題（50 問の配列）
    figures/<examId>/qNN.png           問題文の図
    figures/<examId>/qNN_choices.png   選択肢が写真・図のときの「答え」欄全体
    figures/<examId>/qNN_choice_K.png  選択肢 1 つぶんの画像（任意）
    figures/<examId>/p15.png           配線図面（配線図問題が共有する）
```

## examId

`denko2-<西暦年度>-<期>` に、午前・午後がある回だけ `-<午前|午後>` を足す。

| examId | year | term | session |
|---|---|---|---|
| `denko2-2026-上期` | 2026 | 上期 | （なし） |
| `denko2-2023-上期-午前` | 2023 | 上期 | 午前 |
| `denko2-2020-下期-午後` | 2020 | 下期 | 午後 |

年は西暦（令和 8 年度 = 2026）。全 27 回の一覧は `data/extracted/denko2/index.json`、
コマンドなら `python3 scripts/extract_pdf.py --list`。

## Question（1 問）

```jsonc
{
  "id": "denko2-2023-上期-午前-12",       // 一意。`<examId>-<問番号>`
  "subject": "denko2",
  "category": 3,                          // 1〜7（subject.json の分野番号）
  "groupId": "g3-ringslv-kumiawase",      // 類似問題グループ。groups.json に定義
  "type": "static",                       // "static" | "calc"
  "premise": "図は，木造2階建住宅の配線図である。…",  // 任意。問題群に共通の前提条件（下記）
  "stem": "①で示す部分に…",               // Markdown 可（**強調**、改行 \n、段落 \n\n）
  "figure": "figures/denko2-2023-上期-午前/q12.png",           // 任意。問題文の図
  "sharedFigure": "figures/denko2-2023-上期-午前/p15.png",     // 任意。配線図面。同じ値の問は連続出題される
  "choicesFigure": "figures/denko2-2023-上期-午前/q12_choices.png", // 任意。選択肢が写真・図のとき
  "choiceFigures": ["…q12_choice_1.png", "…", "…", "…"],       // 任意。選択肢 1 つずつの画像
  "choices": ["イの本文", "ロの本文", "ハの本文", "ニの本文"],   // 必ず 4 つ
  "answer": 1,                            // 0=イ 1=ロ 2=ハ 3=ニ。公式解答と一致させる
  "shuffleChoices": true,                 // 任意。既定は static=true、calc と choicesFigure あり=false
  "explanation": {
    "whyCorrect": "正答の根拠。条番号・公式を添える",
    "whyOthersWrong": ["イが違う理由", "", "ハが違う理由", "ニが違う理由"], // 任意。4 要素、正答の位置は ""
    "supplement": "正解したときにも出す補足・周辺知識・覚え方",
    "references": ["電技解釈 第29条", "内線規程 1350-3"]
  },
  "calcTemplate": { /* type が "calc" のとき。下記 */ },
  "status": "active",                     // "active" | "retired"
  "retiredReason": "…",                   // retired のとき必須
  "note": "現行法では「一般用電気工作物等」。出題当時の表記のまま掲載", // 任意。出題時に表示
  "source": { "year": 2023, "term": "上期", "session": "午前", "number": 12 },
  "tags": ["リングスリーブ"]               // 任意
}
```

仕様にないキーは無視される。見本ファイルの `_comment` のような注釈を残しても検証は通る。

## 表記の規約

- **単位は半角**（`100 V`、`1.6 mm`、`0.1 MΩ`）。数値と単位の間に半角スペースを入れる
- **句読点・括弧は原文どおりの全角**（`，` `。` `〔〕`）。実試験の表記をそのまま残す
- **4 桁以上の数値は半角スペースで 3 桁区切り**（`1 600 W`、`1 440`）。実試験の書き方に合わせる。
  計算問題でアプリが生成する数値も同じ規則で表示される
- **記号は正しい文字を使う**。PDF 抽出では Ω が `W`、φ が `f` に化けるので必ず直す。
  `mm²` の上付きも失われるため補う
- 実試験の太字（**不適切なものは**、**誤っているものは**）は `**…**` で再現する

## 選択肢について

- 「イ・ロ・ハ・ニ」は表示位置のラベルであり、アプリが毎回シャッフルする（`shuffleChoices: false` を除く）。
  `choices` の並びは PDF の並びのままでよい
- 数値の選択肢は `"2.5"`、`"1 600"` のように単位なしの文字列。単位は問題文側の `〔Ω〕` などが担う
- 選択肢が写真・図のときは、`choicesFigure` に「答え」欄全体の画像（イ〜ニのラベルが写ったもの）を入れる。
  `shuffleChoices` は自動で `false` になる

`choices` の文字列は、写真・図の選択肢でも次の基準で書き分ける。

| 問の型 | 書き方 | 例 |
|---|---|---|
| 選択肢そのものが答えの識別対象（「この図記号の器具の写真は」など、説明を書くと答えになる） | ラベルのみ | `["写真イ", "写真ロ", "写真ハ", "写真ニ"]` |
| 選択肢が条件の組合せを表す（リングスリーブの種類と個数、コネクタの本数、測定方法の図など） | 内容を短く | `["小 3個", "小 4個", "小 3個と中 1個", "小 1個と中 2個"]` |

後者は画像が見づらい環境でも解けるようにするため。

## premise（問題群に共通の前提条件）

実試験では、配線図問題の冒頭に「図は，木造2階建住宅の配線図である」と【注意】1〜8（屋内配線は VVF の
ケーブル工事、漏電遮断器は定格感度電流 30 mA・動作時間 0.1 秒以内、3 路スイッチの「0」端子は電源側又は
負荷側 など）が印刷されている。これらは 20 問すべての答えの根拠になる。

本アプリは 1 問ずつランダムに出題するため、この前提を各問に持たせて単独で解けるようにしている。
`premise` は問題文の上に折りたたみで表示される（開かなくても図と問題文は読める）。

- **配線図問題（分野 6）には必ず付ける。** 同じ回の 20 問には同じ文字列を入れる
- 内容は答えに効くものに絞る（構造・階数、ケーブルの種類、漏電遮断器の定格、分電盤の外箱、
  写真の器具が一般形であること、3 路の「0」端子、ジョイントボックスでの接続）
- 一般問題でも「ただし」書きが複数問にまたがる場合は使ってよい
- 出典元は各回の問題 PDF の 11 頁目。`data/extracted/denko2/<examId>/pages/p11.png` で読める

## 図について

- 図がないと解けない問（「図のような回路で」「①で示す」など）には必ず画像を付ける
- `scripts/extract_pdf.py` が `cells/qNN_figure.png`（自動切り出し、テキスト PDF のみ）と
  `cells/qNN_stem.png`（「問い」欄全体）を出力する
- `scripts/publish_figures.py <questions.json>` が参照先を `public/data/denko2/figures/<examId>/` にコピーする。
  `qNN.png` は `cells/qNN_figure.png` → `cells/qNN_stem.png` の順に解決される
- 手で切り出した画像は `data/extracted/denko2/<examId>/custom/<name>.png` に置けば同じ仕組みでコピーされる
- 配線図問題（分野 6）は `sharedFigure` に図面を指定する。図面は全 27 回とも PDF の 15 頁目（`pages/p15.png`）

## 計算問題での表示

`type: "calc"` の問では、アプリは `calcTemplate.explanation` と `explanation.supplement` を表示し、
`whyCorrect` と `whyOthersWrong` は表示しない（誤答が実行時に生成されるため対応が取れない）。
解き方は `calcTemplate.explanation` だけで完結するように書く。`whyCorrect` は検証で必須なので、
根拠を 1〜2 文で残しておく。

## CalcTemplate

```jsonc
{
  "params": { "V": [100, 200], "R": [10, 20, 25, 40, 50, 100] }, // キリのよい値のプール。元問題の値を必ず含める
  "formula": "V * V / R",                      // 正答を返す JS 式。params の名前と Math が使える
  "accept": "answer >= 100 && answer <= 4000", // 任意。実試験らしい範囲だけ採用
  "distractors": ["answer / 2", "answer * 2", "V * R / 10"], // 誤答の式。正答と重複したものは捨てて自動補充
  "unit": "W",
  "round": 0,                                  // 丸め桁（小数点以下）
  "explanation": "P = V²/R = {V}² ÷ {R} = **{answer} W**", // {パラメータ名} と {answer} を置換
  "original": { "V": 100, "R": 25 }            // 元の過去問の値。params に含まれていること
}
```

- `stem` でも `{V}` `{R}` のようにパラメータを参照する。元の数値を直接書かない
- 図の中に数値が描かれている問は calc にしない（図の数値が変わらず矛盾する）。
  ただし「各抵抗は {R} Ω」のように問題文で言い換えられる場合はよい
- 検証は全組合せを実行し、「採用可能な組合せが 1 つ以上」「正答が選択肢に一意に存在」「選択肢が重複しない」を確認する

## groups.json

```jsonc
{
  "subject": "denko2",
  "groups": [
    {
      "id": "g5-zetsuen-teikou-kijun",
      "name": "絶縁抵抗の基準値",
      "category": 5,
      "summary": "対地電圧区分ごとの基準（0.1 / 0.2 / 0.4 MΩ）",
      "relatedGroups": ["g6-zetsuen-teikou-zumen"]  // 任意
    }
  ]
}
```

- 粒度は「1 問解ければ同グループの他問も解ける」レベル
- `id` は `g<分野番号>-<ローマ字の短い名前>`。人間が読んで意味が分かること
- 1 グループは 1 分野に属する（検証が確認する）。分野をまたいで同じ知識を問う場合は別グループにし、
  `relatedGroups` で関連付ける（現状は記録用で、出題制御には使っていない）

## subject.json

| キー | 意味 |
|---|---|
| `categories[].examCount` | 実試験 50 問中の出題数の目安。デイリー 30 問の分野別最低数はこれに比例する |
| `questionFiles` | `questions/` 配下で読み込むファイル名。**新しい回を追加したら必ず追記する** |
| `exam` | 模擬試験の問数・制限時間・合格基準 |
| `citation` | 出典表記のテンプレート。`{year}` `{term}` `{session}` `{exam}` を置換する |

## 検証が見ていること

`npm run validate` の内容（`scripts/validate-data.ts`）。

- 必須項目、`choices` が 4 つ、`answer` が 0〜3、`category` が `subject.json` に存在
- `id` の重複、`groupId` が `groups.json` に存在（なければ警告）、1 グループが複数分野にまたがっていない
- `whyCorrect` と `supplement` が空でない、`whyOthersWrong` があるなら 4 要素
- `status` が `active` か `retired`、`retired` に `retiredReason` がある（なければ警告）
- `source` に `year` `term` `number` が揃っている
- 参照している画像ファイルが実在する
- `calcTemplate` の全組合せで正答が選択肢に一意に存在し、採用可能な組合せが 1 つ以上ある
- `questions/` にあるのに `questionFiles` に載っていないファイルがある（警告）

公式解答との突き合わせは validate では行わない。`python3 scripts/check_answers.py <examId>` で別に確認する。

## explanation.simple（「もっと分かりやすく！」）

解説カードの下に、専用の枠で常に表示される。正解・不正解にかかわらず出るので、
**この欄だけ読めば何を問われたのかが分かる**ように書く。

- 対象読者は電気の予備知識がない人。専門用語をできるだけ使わず、使うときは直後に噛み砕く
- **3〜5 文**。実試験の言い回しをなぞらず、日常の言葉で言い換える
- 身近な例え（水とホース、水道の蛇口、家電など）を使ってよい。ただし**例えが誤解を生むなら使わない**
- 「なぜそうなるのか」の芯を1つに絞る。周辺知識は `supplement` の役目なので繰り返さない
- 引っかけどころがある問は、どこで引っかかるのかを名指しする
- 計算問題では、式の意味を言葉で説明する（数値は毎回変わるので具体値に依存しない書き方にする）
- Markdown の `**強調**` が使える。段落を分けるときは空行

書き方の例（絶縁抵抗の基準値を問う問題）:

> 電気が漏れていないかを調べるのが絶縁抵抗の測定です。「どれくらい漏れにくければ合格か」の基準は、
> 使っている電圧ではなく**大地との間の電圧（対地電圧）**で決まります。
>
> ここが一番の引っかけどころ。単相3線式の200 V回路は、電線1本ずつで見ると大地との間は100 Vなので
> 基準はゆるい方（0.1 MΩ）です。いっぽう三相3線式200 Vは大地との間も200 Vあるので、
> きびしい方（0.2 MΩ）が必要になります。

## glossary.json（用語辞典）

`public/data/<subject>/glossary.json`。全問で共有し、問題文・解説の本文に出てきた語を
自動でタップできるようにする。1 問ずつに用語解説を持たせないのは、同じ語が何十問にも出るため。

```jsonc
{
  "subject": "denko2",
  "terms": [
    {
      "term": "絶縁抵抗",              // 見出し語。本文中の表記に合わせる。2文字以上
      "reading": "ぜつえんていこう",     // よみ（ひらがな）
      "short": "電気の漏れにくさを表す値", // 一言で。40字以内、できれば20字程度
      "plain": "電線をつつむビニルの皮が…", // 噛み砕いた説明。2〜4文。例え可
      "aliases": ["絶縁抵抗値"],         // 表記ゆれ・略記。これらもタップ対象になる
      "category": 5,                    // 主に出てくる分野（任意）
      "related": ["絶縁抵抗計", "対地電圧"] // 辞典内の term のみ。シートからたどれる
    }
  ]
}
```

- **本文中の照合は「一番長く一致する語」を採る。** 「絶縁抵抗計」と「絶縁抵抗」が両方あるとき、
  前者が優先されて途中で切れない。したがって長い複合語も遠慮なく登録してよい
- **1 文字の見出し・別名は禁止**（他の語の一部に誤って一致するため。検証がエラーにする）
- 同じ語は 1 問につき 1 回だけ下線が付く。本文が下線だらけにならないようにするため
- `related` は辞典内に実在する `term` のみ（検証がエラーにする）
- ありふれた一般語（「電気」「工事」「使用」など）は登録しない。**受験者がつまずく語**だけにする
